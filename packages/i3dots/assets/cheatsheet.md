# i3dots — Atajos de Teclado

Guía rápida de atajos de teclado y controles del sistema.

## ❖ Sistema e Interfaz

| Atajo | Acción |
| :--- | :--- |
| <kbd>super</kbd> + <kbd>Enter</kbd> | Abrir Terminal (Kitty) |
| <kbd>super</kbd> + <kbd>Q</kbd> | Cerrar Ventana Enfocada |
| <kbd>super</kbd> + <kbd>D</kbd> | Menú de Aplicaciones (Rofi Launcher) |
| <kbd>super</kbd> + <kbd>X</kbd> | Lanzador Rápido (Rofi Run) |
| <kbd>super</kbd> + <kbd>E</kbd> | Gestor de Archivos (Nemo) |
| <kbd>super</kbd> + <kbd>Tab</kbd> | Menú de Apagado (Powermenu) |
| <kbd>super</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> | Recargar Configuración de i3 |
| <kbd>super</kbd> + <kbd>Shift</kbd> + <kbd>R</kbd> | Reiniciar i3wm |

## ✦ Gestión i3dots

| Atajo | Acción |
| :--- | :--- |
| <kbd>super</kbd> + <kbd>W</kbd> | Selector de Fondos de Pantalla (Matugen) |
| <kbd>super</kbd> + <kbd>Shift</kbd> + <kbd>B</kbd> | Cambiar Estilo/Tema de Barra (Polybar) |
| <kbd>super</kbd> + <kbd>Shift</kbd> + <kbd>M</kbd> | Cambiar Opciones de Barra (Altura, etc.) |
| <kbd>super</kbd> + <kbd>Shift</kbd> + <kbd>D</kbd> | Administrar Pantallas y Resolución |
| <kbd>super</kbd> + <kbd>H</kbd> | Alternar Visor de Atajos (Cheatsheet) |
| <kbd>super</kbd> + <kbd>R</kbd> | Entrar en Modo Redimensionar |

##  Capturas de Pantalla (Screenshots)

| Atajo | Acción |
| :--- | :--- |
| <kbd>Print</kbd> | Capturar pantalla completa al Portapapeles |
| <kbd>super</kbd> + <kbd>Print</kbd> | Capturar ventana activa al Portapapeles |
| <kbd>super</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | Capturar área seleccionada al Portapapeles |
| <kbd>Ctrl</kbd> + <kbd>Print</kbd> | Guardar captura de pantalla completa en Disco |
| <kbd>super</kbd> + <kbd>Ctrl</kbd> + <kbd>Print</kbd> | Guardar captura de ventana activa en Disco |
| <kbd>Shift</kbd> + <kbd>Print</kbd> | Guardar captura de área seleccionada en Disco |

## 󰕾 Audio y Brillo

| Atajo | Acción |
| :--- | :--- |
| <kbd>super</kbd> + <kbd>F12</kbd> / <kbd>F11</kbd> | Subir / Bajar Volumen |
| <kbd>super</kbd> + <kbd>F10</kbd> | Silenciar / Activar Audio (Toggle Mute) |
| <kbd>super</kbd> + <kbd>Shift</kbd> + <kbd>F12</kbd> / <kbd>F11</kbd> | Subir / Bajar Brillo de Pantalla |
